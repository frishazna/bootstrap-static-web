# KampusKita - Website Statis Bootstrap

Website landing page sederhana yang dibuat untuk praktikum Pengembangan Aplikasi Web.

## Teknologi
- HTML5
- CSS3
- Bootstrap 5 (CDN)
- Bootstrap Icons (CDN)

## Struktur folder
bootstrap-static-website/
├── index.html
├── css/
│   └── style.css
└── README.md

## Cara menjalankan
1. Ekstrak folder project.
2. Buka folder `bootstrap-static-website` di Visual Studio Code.
3. Buka file `index.html` menggunakan browser, atau jalankan dengan ekstensi Live Server.
4. Pastikan koneksi internet aktif agar Bootstrap CSS, Bootstrap Icons, dan Bootstrap JavaScript dari CDN dapat dimuat.

Website ini bersifat statis. Tombol navigasi mengarah ke bagian halaman, sedangkan tombol Hubungi Kami membuka aplikasi email.
